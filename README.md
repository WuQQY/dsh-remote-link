# dsh-remote-link

**在 iPhone 上不装 App、不做 iOS 开发，就能远程用这台电脑上的 DeepSeek Harness。** 用 Safari 打开 → 分享 → 添加到主屏幕，之后点图标就跟 App 一样。同一个工作区、同一个会话、同一份上下文：能对话、能看实时输出、能点审批、能改权限。

不需要开发 iOS 应用，不需要公网 IP，不需要改路由器，也不用买短信服务。

---

## 它解决什么问题

DSH 的 Web 服务有三个前提，直接拿域名或公网 IP 去连是连不上的：

1. 只监听 `127.0.0.1`，外部连不到；
2. 每个请求要一枚按 authority（`127.0.0.1:<port>`）签名的浏览器会话 cookie，换域名就对不上；
3. 还有 Host / Origin 围栏，非本机 Host 的 `/api` 直接 403。

这个插件在本机起一层回环桥接，一次解决三件事：用宿主给的签名密钥现铸 cookie、把 Host 改写成回环、丢掉 Origin。外部入口由你选：

- **局域网**：桥接监听 `0.0.0.0`，同一 Wi-Fi 下直接连 `http://192.168.x.x:<port>/`；
- **frp 中继**：自己搭建一台中转服务器（VPS 等）当跳板，适合长期在外用；
- **Cloudflare quick tunnel**：免费、零配置，但每次重启换域名、延迟较高，适合临时用一下。

三条入口前面都有一道登录门：手机号 + 验证器动态码（TOTP）。

> 插件不包含也不推荐任何中继服务器。你可以只用局域网、用免费的 Cloudflare 隧道，或自己搭建中继——地址由你在设置页填写，项目本身不提供公共中继服务。

## 安装

```bash
# 在 DSH 的 profile 里安装（把 <本仓库路径> 换成你克隆下来的目录）
dsh plugin add <本仓库路径>
```

装完后打开 **设置 → 远程链接**。

隧道客户端 `bin/cloudflared.exe`（约 53 MB）**不在仓库里**，首次使用前需要自备：

1. 从 [Cloudflare 官方发布页](https://github.com/cloudflare/cloudflared/releases) 下载对应平台的 `cloudflared`；
2. 放到本插件的 `bin/` 目录下（Windows 命名为 `cloudflared.exe`，其它平台 `cloudflared`）；
3. 设置页的「隧道客户端」会显示 `present` / `missing`。

不用 Cloudflare、只走局域网或 frp 中继的话，可以不装它。

## 使用

1. 在 **设置 → 远程链接** 填手机号，验证码通道保持「验证器 App（推荐）」，保存；
2. 点「开启」——桥接起来，需要的话再开隧道；
3. 点「显示认证器」，用验证器 App（iOS 密码、1Password、Authy 等）扫 `①` 那个二维码，**只做一次**；
4. 用手机相机扫 `②` 那个二维码打开链接，Safari 里是登录页，填验证器里的 6 位数字；
5. 登录后点 Safari 的分享 → **添加到主屏幕**，之后点图标就用，30 天内不用再登。

### 多台设备

没有设备数量限制，也不需要额外配置：

- 每台手机各自打开链接、用**同一把**验证器密钥登录；
- 每次登录都会签发一枚**独立**的会话（各自有独立 jti），互不影响；
- 换手机、卖旧手机时，在设置页点「注销所有设备」即可让全部旧会话立刻失效；
- 手机端胶囊里的「断开这台设备」只作废当前这台，不影响其它设备。

### 自己搭建中继（可选）

如果要用 frp 中继，需要你自己准备一台中转服务器，在上面跑 `frps`，并在自己电脑上跑 `frpc` 映射到本机桥接。插件里填你自己那一条中继地址（`https://你的地址:你的端口/`）即可。

插件本身不内置 frpc、不提供中继服务器、也不含任何 token——`frpc.ini` / `frps.toml` 由你自己维护。`frps` 的 `auth.token` 是你自己的凭据，不要写进本仓库或任何公开文档。

不想搭服务器的话，直接用局域网入口或免费的 Cloudflare 隧道就行，功能完全一样。

## 安全说明

- **登录门**：桥接不判断身份，只认登录门放行与否；未登录的 API 返回 401，页面导航 303 到登录页，WebSocket 直接 401 断开。
- **管理接口本机专用**：`/api/remote-link/*` 过 `localOnly`（回环 + Host 字面量 + 无转发头 + 无 `x-dsh-via`），经桥接或公网一律拒绝。
- **审计来源不信任客户端**：限流键用手机号 + socket 地址，不读 `cf-connecting-ip` / `x-forwarded-for`，转发头可伪造所以不采信。
- **动态码防重放**：同一时间片的码成功用过一次就作废，只保留最近几个时间片。
- **退出即吊销**：`/__logout` 会先验签再把该会话 jti 记入吊销名单，伪造的 cookie 无法污染名单。
- **密钥不落日志**：长期 TOTP 密钥默认不下发，只有显式点「显示」才返回一次。

已知局限：

- 会话吊销名单只在内存里，重启 DSH 即清空（等同「关掉电脑就等于全部下线」）；
- quick tunnel 每次重启换域名，这是 Cloudflare 的产品限制；
- 局域网入口是明文 HTTP，别忘了这一点。

## 目录结构

```
index.js              宿主侧装配：桥接 + 登录门 + 隧道 + 设置接口
client.js             浏览器侧：设置页、侧栏连接胶囊、手机滑动手势
cordis.patch.yml      bundle 挂载
lib/auth.js           登录门：手机号 + TOTP、限流、会话签发与吊销
lib/bridge.js         回环桥接：HTTP / WebSocket 转发、来源识别、/__ping
lib/host-state.js     隧道进程管理、局域网/Tailscale 地址发现
lib/routes.js         设置接口 + localOnly 守卫
lib/mint.js           DSH 浏览器会话 cookie 现铸
lib/totp.js           TOTP（RFC 6238）
lib/qr.js             二维码编码（无第三方依赖）
locale/*.json         插件元信息与界面文案
docs/DETAIL.md        插件详情页
```

## 开发

零第三方运行时依赖。清单校验、二维码、TOTP 全部自带实现。

```bash
node --check index.js
node --check client.js
```
