# 远程链接

在手机浏览器里用这台电脑的 DeepSeek Harness：能对话、能看实时输出、能点审批、能改权限。
不装 App、不要公网 IP、不改路由器、不买短信。

## 它解决的是什么

DSH 的 Web 服务有三个前提，直接拿隧道域名怼进去是打不开的：

1. 只监听 `127.0.0.1`，外部连不到；
2. 每个请求要一枚按 authority（`127.0.0.1:<port>`）签名的浏览器会话 cookie，换域名就对不上；
3. 还有 Host / Origin 围栏，非本机 Host 的 `/api` 直接 403。

插件在本机起一层回环桥接，把这三件事一次解决：用宿主给的签名密钥现铸 cookie、
把 Host 改写成回环、丢掉 Origin；隧道由 `cloudflared` 主动出站，所以手机在 4G、
在别人 Wi-Fi、在酒店，都一样能连。

## 怎么用

打开 **设置 → 远程链接**，按顺序做三件事：

1. **填手机号**（只认这一个），验证码通道保持「验证器 App（推荐）」，点保存。
2. **点「开启」**。桥接起来、隧道连上，几秒后出现两个二维码。
3. **手机扫码**：
   - 先扫「① 加进验证器」——只在第一次做，用 iOS 自带「密码」App 或任意验证器 App。
     扫不了就把下面那串密钥手输进去。
   - 再扫「② 手机打开这条链接」，Safari 打开后是登录页，填验证器里那 6 位数字。

进去之后点 Safari 的分享 → **添加到主屏幕**，之后点图标就用，30 天内不用再登录。

## 两种验证码通道

| 通道 | 怎么拿到码 | 花钱 | 人在外面能用 |
|---|---|---|---|
| `totp`（默认） | 手机验证器 App 每 30 秒变一次的 6 位数字 | 免费 | 能 |
| `console` | 验证码打印在跑着 DSH 的那个终端窗口 | 免费 | 不能（看不见电脑） |

## 手机上能做什么

进去就是这台电脑上**完整**的 DSH 网页版，不是只读镜像：

- 发消息给 agent，它会真的在电脑上执行；打断、排队插话都可以
- agent 干活的过程实时流式出现（走 WebSocket `/api/remote.mux`）
- 需要你同意的时候，审批卡片直接出现在手机上，点同意或拒绝
- 设置里能切 read-only / workspace-write / danger-full-access
- 换模型、开会话、改名、归档、分叉、看工作区文件

## 安全边界

- **拿到你手机（且能解锁）的人就能进这台电脑。** 登录态 30 天，手机丢了先在这里点「关闭」。
- **验证器密钥泄露等于别人能登录。** 那串密钥只存在本机的 `~/.dsh/remote-link.json`，别截图外发。
- **隧道域名每次重启都变**，而且公开可达；别人打开只会看到登录页，门锁在你的动态码上。
- **流量经 Cloudflare 边缘，没有端到端加密**（和 ngrok / frp 同一个模型），别用它处理绝密材料。
- 桥接只绑 `127.0.0.1`；点「关闭」或退出 DSH，隧道与桥接一起消失，DSH 本体不受影响。

## 设计上的几个取舍

**为什么不用 DeepSeek 账号登录。** DeepSeek 没有对第三方开放手机号验证码登录，硬接只能靠抓它的
登录流程、把账号凭据交给自建服务 —— 那等于伪造身份，所以这里做的是同样的形式、自己的验证源。

**为什么默认开 quick tunnel。** Named tunnel 要先 `cloudflared tunnel login` 在浏览器里点授权，
放进插件就把「装完可用」变成「先配置」。quick tunnel 的代价只是域名每次都变。
想要固定域名可以在自己的 Cloudflare 账号上做一条 named tunnel，把 `bin/cloudflared` 换成带令牌的启动方式。

**为什么隧道不自动开。** 装插件不等于同意把它开上公网。要开机自动开，把插件配置的
`autoTunnel` 设成 `true`。

**为什么登录门在桥接里而不是在 DSH 里。** DSH 看到的每个请求都必须是「本机」的，
才有 session cookie 与 Host 围栏；身份判断只能放在这层前面。

## 配置项

插件在 `cordis.patch.yml` 里的 `config`：

| 键 | 默认 | 含义 |
|---|---|---|
| `phone` | `''` | 登录手机号；留空就在设置页里填（填进状态文件，不写回 profile） |
| `channel` | `totp` | `totp` / `console` |
| `bridgePort` | `0` | 桥接端口，0 = 每次让系统挑 |
| `autoTunnel` | `false` | 装完是否自动开隧道 |

## 运行时文件

只写本机一个状态文件：`~/.dsh/remote-link.json`（手机号、验证器密钥、登录签名密钥、
上次的隧道地址）。不含 DSH 的任何凭据，也不改 profile 的配置。
卸载插件时隧道与桥接会一起停掉；那个状态文件留着，重新装回来还是同一份登录密钥。
